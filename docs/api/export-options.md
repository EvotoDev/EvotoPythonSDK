# `evoto.export_options`

`ExportOptions` is the builder for the `options` dict accepted by
[`ExportAPI.start_with_custom()`](export.md). The enums on this page
spell out every legal value the host accepts so plugin code does not
need to hard-code raw strings.

::: evoto.export_options.ExportOptions
    options:
      heading_level: 2
      show_root_heading: true
      show_root_toc_entry: true
